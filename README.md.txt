# LabTrack 🔬

Gestor integral para laboratorios de investigación. Permite controlar experimentos, muestras, equipamiento y trazabilidad de resultados.

## Requisitos
- Python 3.9+

## Instalación y Entorno Virtual
1. Clonar el repositorio: `git clone <tu-repo>`
2. Crear entorno virtual: `python -m venv venv`
3. Activar entorno virtual:
   - Windows: `venv\Scripts\activate`
   - Linux/Mac: `source venv/bin/activate`
4. Instalar dependencias de desarrollo: `pip install -e .[dev]`
