### \# LabTrack 



Gestor integral para laboratorios de investigación. Permite controlar experimentos, muestras, equipamiento y garantizar la trazabilidad completa de los resultados.



\## Requisitos

\- \*\*Python 3.9\*\* o superior.

\- \*\*Git\*\* (para el control de versiones).



\## Instalación y Configuración del Entorno



1\. \*\*Clonar el repositorio:\*\*

&#x20;  ```bash

&#x20;  git clone \[https://github.com/alonsovillalbapintado/Trabajo-TCA-Gestor-de-Laboratorio.git](https://github.com/alonsovillalbapintado/Trabajo-TCA-Gestor-de-Laboratorio.git)

&#x20;  cd Trabajo-TCA-Gestor-de-Laboratorio



1. Crear el entorno virtual:



python -m venv venv



2\. Activar el entorno virtual:



&#x09;-En Windows (PowerShell):



venv\\Scripts\\actívate



&#x09;-En Linux/macOS:



source venv/bin/actívate



3\. Instalar las dependencias de desarrollo:



pip install -e .\[dev]



4\. Ejecución



Para iniciar la Prueba de Concepto (PoC) y acceder al menú interactivo principal, ejecuta el siguiente comando con el entorno virtual activado:



python -m src.main



4\. Pruebas



El proyecto cuenta con un sistema de pruebas automatizadas configurado. Para lanzar la batería de pruebas inicial (Smoke Tests):



pytest tests/
